# 2026-10-15 浏览器验收记录

范围：Chrome 实际渲染 GameApp 与浏览器 localStorage；认证与 AI 响应使用专用本机模拟。测试页面只由 `node scripts/acceptance/browser.mjs` 启动，监听 127.0.0.1:4175，不属于 Next.js 路由，不部署为生产登录入口。

已操作和观察：

1. 模拟账号 A 进入沈知夏聊天，设置下一次请求失败，发送“账号A的验收消息”。原消息显示“失败 / 模拟网络失败 / 重试发送”，没有新增角色错误回复。
2. 点击重试，原用户消息仅一条，出现“验收回复：我收到啦。”，文字额度为 99。
3. 切到模拟账号 B：初始角色选择页，进入聊天只有 B 的问候语，文字额度 100，没有 A 的消息。
4. 切回 A：恢复原用户消息、模拟回复和额度 99。

其余断网、超时、卸载晚到请求和媒体数据库隔离由回归测试覆盖。真实生产账号认证、真实 AI 计费请求、跨设备同步、线上发信不属于这次浏览器测试结论。
